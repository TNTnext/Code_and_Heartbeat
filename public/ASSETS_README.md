# 游戏资源文件说明

## 背景音乐 (BGM)
- `bgm-main.mp3` - 主菜单背景音乐
- `bgm-gameplay.mp3` - 游戏进行中背景音乐

## 角色立绘
- `dingle-normal.jpg` - 丁乐 - 正常表情
- `dingle-happy.jpg` - 丁乐 - 开心表情
- `dingle-shy.jpg` - 丁乐 - 害羞表情
- `dingle-blush.jpg` - 丁乐 - 脸红表情
- `dingle-sad.jpg` - 丁乐 - 难过表情
- `dingle-angry.jpg` - 丁乐 - 生气表情
- `dingle-focused.jpg` - 丁乐 - 专注表情
- `dingle-tsundere.jpg` - 丁乐 - 傲娇表情
- `dingle-reading.jpg` - 丁乐 - 读书姿态

## 场景背景
- `bg-dorm.jpg` - 宿舍背景
- `bg-classroom.jpg` - 教室背景
- `bg-night.jpg` - 夜晚背景

## 注意事项
这些文件需要手动添加到 `public/` 目录下。
如果没有这些文件，游戏仍然可以正常运行，只是不会显示对应的图片或播放背景音乐。
